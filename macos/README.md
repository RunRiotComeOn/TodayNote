# 今日 · TodayNote for macOS

一个可以置顶的简约待办便利贴。macOS 11 或更新版本可用，同时包含 Apple 芯片（M 系列）和 Intel 代码，不需要安装开发环境、Python、Node 或其他运行时。

## 使用

1. 解压下载的 ZIP。
2. 将 `TodayNote.app` 拖入“应用程序”文件夹，再双击打开。
3. 如系统因未公证的开发者而拦截，请先尝试打开一次，然后在“系统设置 → 隐私与安全性”中对“今日”选择“仍要打开”，再按系统提示确认。旧系统对应“系统偏好设置 → 安全性与隐私”。这份个人应用没有 Apple Developer ID 签名或公证，不需要关闭系统的安全检查。

打开后在底部输入内容，按 Enter 或加号添加。紧急程度和重要程度各分低、中、高三档，可在添加前选择，也能直接点击事项下的标签修改。

- 点圆圈完成，文字划线，当天继续保留在原位。再点一次可取消完成。
- 双击待办文字编辑；悬停后点右侧省略号或右键，可编辑、删除；删除后可以撤销。
- 拖动窗口顶部移动，拖动窗口边缘调整大小。
- 图钉控制置顶，齿轮打开设置。
- 红色关闭按钮只隐藏窗口；从屏幕顶部菜单栏的勾选图标可重新打开。
- 真正退出：菜单栏“退出”、设置中的“退出软件”，或 Command+Q。
- Command+N 聚焦新待办，Command+, 打开设置，编辑窗口中 Command+Enter 保存，Esc 关闭弹窗。

## 换日与记录

默认在本机时间凌晨 04:00 换日。例如 11 月 6 日凌晨 01:00 仍属于 11 月 5 日，到凌晨 04:00 才进入 11 月 6 日。

设置可精确到分钟。到点后，未完成事项延续，已完成事项收进窗口右下方的“完成记录”。软件未运行、电脑休眠或关机跨过换日时间，下次打开或唤醒时也会自动处理。即使修改系统时间或换日时间，也不会倒退到已经归档的一天。

## 外观与其他设置

- 浅色、深色、跟随系统，选择后立即生效并自动记住。
- 窗口置顶、开机启动、优先级排序、换日时间、字号。
- 开机启动默认关闭。开启前请先把应用放到“应用程序”文件夹；开启后会在下次登录时启动，macOS 也可能要求允许该登录项。
- 优先级排序默认关闭，因此勾选事项不会突然换位置。开启后先显示未完成项，按“紧急 + 重要”总分排列，同分时重要程度高的靠前。
- 置顶可以覆盖普通应用窗口；macOS 的锁屏、系统安全对话框及部分独占全屏画面由系统控制。

## 本地数据与迁移

所有待办保存在本机的 `~/Library/Application Support/TodayNoteMac/data.json`，保存时原子替换文件，并保留上一次的 `.bak`。程序不连接服务器，不上传待办内容。

设置中可导出和恢复 JSON 备份。Mac 和 Windows 版使用相同的备份格式：先在原电脑导出，再在另一台电脑恢复即可。没有云端自动同步。

恢复前会自动另存当前内容；无法读取的主文件会尽量从备份恢复，同时保留原文件。保存失败会显示“未保存 · 点击重试”，此时请先导出备份。

开机启动由当前 Mac 单独管理，不随备份改变。窗口位置由 macOS 单独记忆。

卸载前请关闭“开机启动”并退出程序，再删除应用。如也要删除待办数据，在 Finder 的“前往 → 前往文件夹”中打开上述数据目录，再自行删除。

## 源码与验证范围

本仓库的 `macos/src/` 保留完整源码。`Native.m` 为 AppKit 窗口、菜单栏、文件对话框与本地保存，界面使用系统 WebKit，不打包额外浏览器。在仓库根目录运行 `bash macos/build-macos.sh`，可在装有 Xcode Command Line Tools 的 Mac 上重新构建通用应用。

Apple 芯片和 Intel 二进制均已编译。已通过 34 项核心逻辑检查和 25 项浏览器界面检查，覆盖跨日、保留完成项、延续未完成项、编辑、删除撤销、深浅与系统主题、备份格式兼容和最小窗口布局。

当前环境为 Linux，因此尚未在 macOS 实机验证 AppKit 窗口、系统 WebKit、菜单栏、置顶、开机启动与原生文件保存窗口。浏览器界面检查使用模拟的本地保存接口，不等同于 Mac 系统层端到端测试。
