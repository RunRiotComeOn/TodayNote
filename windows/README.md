# 今日 · TodayNote

一个安静的 Windows 桌面待办便利贴。灰白色、独立窗口、默认置顶，所有数据保存在本机，不需要账户或联网。

## 打开

1. 把整个压缩包解压到一个固定文件夹。
2. 双击 `TodayNote.exe`，即可使用。不要直接在压缩包内运行。
3. 如需以后方便打开，在齿轮设置中点“创建桌面快捷方式”。

适用 Windows 10 / 11，使用 .NET Framework 4.8。无需安装 Python、Node 或其他开发工具。`TodayNote.exe.config` 请与程序放在同一个文件夹。

## 日常使用

- 在底部输入待办，按 Enter 或点加号添加。每项支持最多 500 字。
- “紧急”和“重要”各有低、中、高三个独立等级。添加前可选择，也能直接点击待办下面的标签修改。
- 点击圆圈完成；文字自动划线，当天仍在原位置保留。再次点击可以取消完成。
- 双击文字编辑，右键可以删除；删除后短时间内可撤销。
- 拖动顶部空白区域移动窗口，拖动右下角调整大小。
- 图钉控制置顶。右上角横线收起到系统托盘，点击托盘图标重新打开。
- Ctrl+N 跳到输入框；Esc 关闭设置、编辑或记录窗口。

## 每天换日

默认在本机时间**凌晨 04:00**换日。例如 11 月 6 日凌晨 01:00 仍属于 11 月 5 日；到凌晨 04:00 才进入 11 月 6 日。

到点后，未完成事项自动继续保留，不重复生成；已完成事项从今天的列表中收起，进入窗口右下方的“完成记录”图标。原来的数据不会删除。关着软件、关机或休眠跨过换日时间也没关系，下次打开或唤醒后会自动更新。

齿轮中可选择换日时间（每半小时一档）。如果在深夜修改时间，只会向前进入新的一天，不会把已经归档的一天重新打开。

## 设置

- 外观：浅色 / 深色 / 跟随系统。选择后即时生效，自动记住；跟随系统时会随 Windows 的“默认应用模式”变化。待办、设置、编辑窗口、完成记录和应用内菜单使用统一配色。
- 窗口置顶；开机启动（默认关闭）。
- 优先级排序（默认关闭，因此完成一条也不会突然跳动位置）。打开后，未完成事项优先，按紧急程度和重要程度之和排序，同分时更重要的在前。
- 每日换日时间；字号。
- 导出备份、恢复备份、创建桌面快捷方式、退出软件。

点击收起或按 Alt+F4 会隐藏到托盘。真正退出可在设置或托盘右键菜单中选择“退出”。

## 从旧版更新

先通过托盘菜单或设置退出旧版软件，再用新版文件替换原程序文件。待办和设置保存在独立的数据目录，会自动保留；旧版数据默认延续浅色外观。在齿轮设置顶部的“外观”中可以切换深色。

1.1.1 修复了 1.1.0 加入外观设置后启动时报“无法设置对象上的属性，因为它处于只读状态”的问题。无需清空数据或重置设置。

## 数据与备份

数据位于 `%LOCALAPPDATA%\TodayNote\data.json`，每次变更立即保存，并保留上一次保存的 `.bak`。程序放在哪里、如何移动，不影响这份本机数据；同一 Windows 用户只会打开一个实例。

如需换电脑，先在设置中“导出备份”，到新电脑再“恢复备份”。恢复前会在原数据目录自动另存当前内容。备份包含待办、完成记录和界面设置；开机启动属于 Windows 本机设置，不会跟随备份改变。

如果磁盘不可写，会显示“未保存”，点击可重试。此时先不要退出，也可以先导出备份。

卸载：先关闭设置里的“开机启动”，退出软件，再删除程序文件夹和桌面快捷方式。如果也想彻底删除数据，另行删除 `%LOCALAPPDATA%\TodayNote`。

## 源码与验证

本仓库的 `windows/src/` 目录保留完整 C# / WPF 源码，便于继续调整。在仓库根目录用 Windows PowerShell 运行 `windows/build.ps1` 可重新生成程序；只使用 Windows 自带的 .NET Framework 编译器。

已完成 .NET Framework 4.8 Windows GUI 程序编译、XAML 结构和主题资源检查，以及 47 项真实 C# 核心逻辑检查，涵盖日期边界、跨年与闰日、关闭多日后延续、完成与取消、排序、中文和 emoji、原子保存及备份校验、外观选择、主题持久化和旧数据兼容。当前构建环境为 Linux，尚未在 Windows 桌面实际运行和验证 UI、托盘、开机启动与多显示器行为。
